¿Qué es DragoDocs AI?

DragoDocs AI es una aplicación móvil para Android diseñada para ayudar a escanear, organizar, convertir, comprimir, firmar y compartir documentos digitales desde un solo lugar.

Integra herramientas de inteligencia artificial como Google Gemini para ofrecer funciones de comprensión documental, resumen y extracción de información.

La aplicación está desarrollada por DragoDocs AI Team y utiliza tecnologías como Firebase, ML Kit, OpenCV, Collabora y PDFBox.

Misión

Facilitar la gestión de documentos digitales mediante una aplicación accesible, segura y potenciada por inteligencia artificial.

Visión

Ser una herramienta de referencia para la organización y procesamiento inteligente de documentos en dispositivos móviles.

Tecnologías

Tecnologías que utilizamos

Gemini

Modelos de inteligencia artificial de Google para análisis de documentos.

Firebase

Backend de Google para autenticación, almacenamiento y sincronización.

ML Kit

Kit de machine learning de Google para reconocimiento de texto.

OpenCV

Biblioteca de visión por computadora para mejora de imágenes.

Collabora

Motor de ofimática para documentos Word, Excel y PowerPoint.

PDFBox

Biblioteca para manipulación de archivos PDF.

Android

Plataforma móvil sobre la que se ejecuta la aplicación.

Jetpack Compose

Toolkit moderno para construir la interfaz de usuario nativa.
