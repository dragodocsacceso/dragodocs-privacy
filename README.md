# DragoDocs AI — Official Website

Sitio web oficial de **DragoDocs AI**, la aplicación de Android para gestionar documentos con inteligencia artificial.

## Descripción

DragoDocs AI permite escanear, organizar, convertir, comprimir, firmar y compartir documentos PDF, Word, Excel y PowerPoint desde dispositivos Android.

## Tecnologías del sitio

- HTML5 semántico
- CSS3 moderno con variables, flexbox, grid, glassmorphism y animaciones
- JavaScript vanilla (ES6+)
- Sin frameworks ni librerías de UI
